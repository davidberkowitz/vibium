Mind Map

Shortcuts

Tab
new child of the selected node
Enter
new sibling of the selected node
F2 / double-click
rename a node
Delete
remove the node and everything under it
Arrow keys
walk the tree (parent / child / siblings)
2 / 3
switch between the flat and orbit view
slider
hold the map part-way between the two
L
re-run the automatic layout
F
fit the whole map on screen
Ctrl+Z
undo
?
show or hide this panel

Mouse

Drag a node
move it (in 3D it slides on the screen plane)
Shift + drag onto a node
re-parent the dragged branch
Drag the background
pan in 2D, orbit in 3D
Wheel
zoom in 2D, dolly in 3D
Double-click the background
add a node there

The map is saved in this browser automatically.
